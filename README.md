# Proyek Pemrograman Mobile
## Deskripsi
Aplikasi latihan untuk belajar pemob
## Pengembang
Nama panggilan / akun GitHub: briliantaprawira
## Status
Proyek awal perkuliahan.
## Tujuan
Memudahkan pengguna untuk memesan layanan transportasi dan makanan.

## Rencana Fitur
1. Pemesanan transportasi (GoRide)
2. Pemesanan makanan (GoFood)
3. Pengiriman barang (GoSend)

## Cara Menjalankan
Jalankan perintah berikut di terminal:
flutter pub get
flutter run
